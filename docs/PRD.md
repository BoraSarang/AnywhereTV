# 어디서나 TV — 제품 요구사항 (PRD)

> 버전: 2.4.0
> 최종 업데이트: 2026-08-18
> 브랜드: `com.borasarang.*` · 개인·가족용

## 1. 제품 개요

집 안 어디서든 거실 TV 채널을 그대로 이어 볼 수 있는 크로스플랫폼 스트리밍 앱.
무료 공식 스트림 + 유튜브 라이브만 사용. 셋톱박스·홈서버·PC 상시 가동 불필요.

## 2. 핵심 사용자

- **1차**: 어르신 포함 전 연령 — UI 단순함/큰 버튼/음성 안내 최우선
- **2차**: 가족 구성원 모두
- **운영자**: 채널 편집은 전용 macOS 앱(Channel Manager)으로 관리

## 3. 타겟 플랫폼 (확정)

| 플랫폼 | 상태 |
|--------|------|
| macOS | ✅ 지원 |
| Android (Phone/Tablet/TV D-pad) | ✅ 지원 (Services: PiP, Android TV D-pad) |
| iOS / iPad / Web | ❌ 제외 (후보만) — v1.2.1에서 제외 확정 |

## 4. 채널 & 콘텐츠

- 지상파·종편·케이블 공식 스트림 + 유튜브 라이브 + **라디오 (audio)** + **dash 소스**
- 채널 30~50개 (공식 채널 리스트 `channels_v{n}.json`, Gist 원격 + 로컬 fopalback)
- **EPG**: 현재 방영중 프로그램명 + 24시간 편성표 타임라인
- **방송 시작 알림**: 겹치는 시간대 프로그램 알림 (EPG 연동)

## 5. 어디서나TV 앱 기능 (v2.4)

- 원터치 채널 전환(좌우 스와이프/◀▶ 버튼) · 자동 재생 복구(3회) · 마지막 시청 채널 복원
- 화면 회전 잠금(가로 고정 토글) · 데이터 절약 모드(360p~1080p, 자동 최저 해상도)
- 채널 검색 · 즐겨찾기(드래그 재정렬) · 시청 기록
- **백그라운드 재생** (Android foreground notification) · **PiP** (Android)
- **TTS 음성 안내** (어르신 UX) · 대형 버튼(56pt+)/고대비 다크 테마/메뉴 2단계 이하
- **대체 URL 페일오버**: 스트림 실패 시 `backupStreamUrl`로 자동 전환

## 6. Channel Manager (macOS 전용 편집기) 기능 (v2.4)

- URL 붙여넣기 → **자동 해석** → **테스트 재생** → 카테고리 → 저장 (Gist 업로드)
- 카테고리 추가/이름 변경/삭제/순서 변경 · 버전 히스토리 자동 기록
- **스트림 헬스체크** (`HealthService`, 동시 4개 검사, 실패 리포트 화면)
- **중복/무결성 검사** (이름/id/스트림 URL/핸들/동영상 중복, 필수 필드 누락, 로고 URL 형식)
- **Undo/Redo + 자동 백업** (스냅샷 스택 50, backups/ 최근 20개)
- **일괄 편집** (다중 선택 → 카테고리 이동/삭제, 실패 채널만 선택)
- **로고 관리** (iptv-org 한국 자동 완성 검색 + 로고 URL 검증 + **AI 로고/채널명 검색**)
- **플레이리스트 Diff** (백업 vs 현재 비교) · **M3U 가져오기/내보내기**
- **라이브 대시보드** (카테고리별 라이브 카운트, 5분 자동 검사)
- **AI 어시스턴트** (Gemini 자연어 → 수정 JSON → Diff 미리보기 → 적용)
- **AI 채널 추천** (자연어 검색 탭 + 사이트 URL 조사 탭 — 유튜브 폴백으로 무료 동작)

## 7. 비목표 (현재)

- iOS/iPad/Web 지원, 넷플릭스 등 유료 OTT 재생, 불법/비공식 스트림, 방송사 인증 로그인

## 8. 오류/사용자 메시지

- 에러코드 `E-{PLATFORM}-{CATEGORY}-{NUM4}` 체계, 사용자 메시지는 `error_message_ko.json` 분리
- AI 할당량 초과 시 안내: `E-MAN-AI-1005` — "Gemini API 할당량을 초과했습니다..."

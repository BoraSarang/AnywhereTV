# 어디서나 TV — 제품 요구사항 (PRD)

> 버전: 1.0.0 (Phase 1)
> 최종 업데이트: 2026-07-28

## 1. 제품 개요

집 안 어디서든(에어컨 튼 방에서도) 거실 TV 채널을 그대로 이어 볼 수 있는 크로스플랫폼 스트리밍 앱.

## 2. 핵심 사용자

- **1차**: 어르신 포함 전 연령 — UI 단순함/큰 버튼 최우선
- **2차**: 가족 구성원 모두

## 3. 타겟 플랫폼

| 플랫폼 | Phase |
|--------|-------|
| macOS (MacBook Pro 14, M1 Max) | Phase 1 |
| Android Phone (Galaxy S22) | Phase 1 |
| iPad (iPad mini 6세대) | Phase 1 |
| iOS (아이폰) | Phase 2 |
| Android Tablet | Phase 2 |

## 4. Phase 1 범위

인터넷 공식 스트림 + 유튜브 라이브로 8개 채널 제공 (셋톱박스/홈서버 불필요)

### 제공 채널

| 채널 | 소스 유형 | 상태 |
|------|----------|------|
| KBS1 | HLS (동적 URL) | 리졸버 필요 |
| KBS2 | HLS (동적 URL) | 리졸버 필요 |
| MBC | HLS (동적 URL) | 리졸버 필요 |
| SBS | HLS (동적 URL) | 리졸버 필요 |
| EBS1 | HLS (정적 URL) | 직접 재생 가능 |
| EBS2 | HLS (정적 URL) | 직접 재생 가능 |
| YTN | 유튜브 라이브 | 직접 재생 가능 |
| 연합뉴스TV | 유튜브 라이브 | 직접 재생 가능 |

## 5. 핵심 기능

- 채널 리스트: 원격 JSON 설정 파일에서 갱신, 로컬 캐시 폴백
- 즐겨찾기: 기본 프리셋 등록, "내 채널" 탭, 즐겨찾기 내 순환
- 채널 전환: 좌우 스와이프 / ◀ ▶ 버튼 + 채널명 오버레이 2초
- HLS / 유튜브 라이브 자동 전환 (sourceType 기반)
- 해상도 설정: 360p / 480p / 720p ("데이터 절약 모드")
- 마지막 시청 채널 복원 (앱 재시작 시 바로 재생)
- 어르신 친화 UI: 버튼 56pt+, 고대비 다크 테마, 메뉴 depth 2단계 이내

## 6. 제약 사항

- 모든 소스는 공식적으로 무료 제공되는 스트림만 사용
- 개인·가족용으로만 사용, 상업적 배포 금지
- URL 변경 대응을 위한 원격 채널 설정 파일 관리
